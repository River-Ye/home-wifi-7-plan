01 / FINAL ANSWER

最後建議：三台 UX7，三台 5 埠交換器。

第 3 台 UX7 藏在弱電箱做網路大腦，金屬箱內不浪費無線電；兩個 AP 都走 Cat6 有線回程、各自用 USB‑C 供電，完全不需要 PoE。

02 / ROUTER ≠ SWITCH

路由器管邊界，交換器管插孔。

這三種角色很常被裝在同一台消費型機器裡，所以才容易混淆。你的方案刻意拆清楚，故障與設定都比較容易定位。

R

路由器／閘道器

負責 PPPoE、DHCP、IPv6、防火牆、VLAN、VPN，以及家裡和 Internet 之間的所有決策。

本案：弱電箱 UX7 ×1

S

交換器

把一條有線網路擴成多個 2.5G 插孔；同一 LAN 裡桌電傳 NAS，資料由交換器直接轉送。

本案：TL‑SG105‑M2 ×3

A

無線基地台 AP

把有線網路變成 2.4 / 5 / 6GHz Wi‑Fi；同一套 SSID 與漫遊設定帶來 Mesh 使用體驗。

本案：客廳、工作室 UX7 ×2

05 / VLAN + FIREWALL

有線全信任，Wi‑Fi 分三區。

這正好符合你的選擇：所有有線設備留在同一個 Main VLAN；只有 IoT 與訪客 Wi‑Fi 被隔離。非管理型交換器在這個前提下足夠，也讓預算留在線材和供電。

VLAN 10 · 192.168.10.0/24

Main

所有有線設備、NAS、AP 管理與主要 SSID。可互相傳檔，也可管理家中網路。

VLAN 20 · 192.168.20.0/24

IoT

家電與低信任裝置。只准 Internet、DNS、NTP；預設不能碰 NAS、Main 或管理頁。

VLAN 30 · 192.168.30.0/24

Guest

訪客上網。啟用 client isolation，阻擋所有 private network 與設備管理介面。

防火牆規則順序

由上到下比對；允許愈少、規則愈清楚，之後愈好維護。

  1. Allow established / related回應既有連線，避免正常封包被擋。
  2. Allow Main → any可信任的電腦、主機與 NAS 正常使用。
  3. Allow IoT → DNS / NTP / WAN只給基本解析、校時與上網。
  4. Drop IoT → Main / private / admin阻擋 NAS、桌電和路由器管理面。
  5. Allow Guest → WAN，其他 Drop訪客只能上網，彼此也隔離。
這裡的邊界要講清楚：TL‑SG105‑M2 會透明轉送 802.1Q 標籤，但不是能限制每埠 VLAN 的管理型交換器。因為你已確認所有實體有線端點都可信，這個簡化成立；若未來房間出租、出現有線 IoT 或想逐埠隔離，就先把弱電箱中央交換器換成 2.5G 管理型。
06 / SIMPLE → ADVANCED

先用穩定基線，再一項項研究。

不要第一天同時開 MLO、320MHz、自動最佳化與所有進階功能。先跑穩一週並備份設定；每次只改一項，才知道問題從哪裡來。

簡易模式：第一週建議值
  • 兩台 AP 使用相同 SSID 與密碼，選 WPA2/WPA3 transition；有舊 IoT 時另外放 IoT SSID。
  • 2.4GHz：20MHz；5GHz：80MHz；6GHz：先 160MHz。兩台 AP 選不重疊頻道，不要都鎖最大功率。
  • MLO、Smart Queues、每晚自動最佳化先關閉；500/500M 不需要靠 QoS 補救。
  • 更新到 latest stable，而非 release candidate；設定完成立刻匯出備份。
進階模式：穩定後再試
  • 開 Fast Roaming 前先確認所有常用裝置相容；走動視訊測試沒有斷線再保留。
  • 320MHz 與 MLO 只對支援的 Wi‑Fi 7 客戶端有意義；分別開啟、分別測速與觀察一週。
  • IoT 需要 AirPlay／Chromecast 時，只開 mDNS，並建立「指定來源 → 指定服務」例外，不要整個 VLAN 放行。
  • 啟用 IDS/IPS 後重測 WAN；UX7 官方標示 2.3Gbps IDS/IPS，對 500M 方案有餘裕。
遠端回家：NAS 與桌電
  • 在 NAS 與桌電安裝 Tailscale，手機先關 Wi‑Fi、用 5G 行動網路測連線。
  • 不要把 SMB、RDP 或 NAS 管理頁直接 port forward 到 Internet。
  • 若未來要用 UX7 內建 WireGuard 當備援，先確認 ISP 提供可被連入的公網 IP。
07 / INSTALL + ACCEPTANCE

照順序裝，當天就能驗收。

安裝前有兩個未知：弱電箱實際空間，以及標示 Cat6 的牆內線與端接品質。先量再下單：UX7 為 117 × 117 × 42.5mm；TL‑SG105‑M2 約 209 × 126 × 26mm，還要留變壓器與散熱間隙。

  1. 量弱電箱、盤點線材

    確認 UX7、交換器、ONT 不互相疊壓，周圍至少留基本進排氣空間。塞不下時，把 UX7 或交換器放入口旁的通風層架，拓樸不變。

  2. 先做有線骨幹

    ONT → UX7 #1 → 中央交換器；再接四個房間孔。客廳與工作室都是「牆孔 → UX7 AP 的 10G 埠 → UX7 2.5G 埠 → 房內交換器」。

  3. 設定中華電信 WAN

    向中華電信確認 PPPoE 帳密與 ONT 模式，讓 UX7 撥號，避免雙重 NAT。IPv6 依現場取得的 prefix delegation 設定；沒有 MOD，所以不需保留 IPTV 專用埠。

  4. 收編兩台 AP

    UX7 #2、#3 選 AP mode，納入 #1 的本機 UniFi Network 管理；關閉 #1 無線電，建立 Main／IoT／Guest 三組網路與 SSID。

  5. 驗證再搬進定位

    先在桌面接完、確認所有設備更新與重新開機正常，再固定到弱電箱和房內位置。這比在箱內反覆拔插安全。

2.2 Gbps+兩台 2.5G 電腦以 iperf3 雙向測；並檢查無 CRC / error。
−65 dBm常用位置 5GHz 目標；低於 −67 dBm 先移 AP，再考慮第 3 點。
